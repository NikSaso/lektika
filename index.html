01 · ΠΩΛΗΣΙΑΚΑ ΛΕΚΤΙΚΑ

Χτίζουν εμπιστοσύνη

✓ Θετικό

Ο στόχος δεν είναι να πιέσεις τον πελάτη. Είναι να καταλάβεις τη χρήση του και να τον βοηθήσεις να δει αν υπάρχει κάτι που πραγματικά του ταιριάζει.

Φράσεις που μειώνουν την πίεση

«Να δω αν σας αφορά»

«Να δούμε αν ταιριάζει στη χρήση σας»

«Αν έχει νόημα για εσάς»

«Εφόσον σας εξυπηρετεί»

«Δεν υπάρχει λόγος να πάτε σε κάτι που δεν χρειάζεστε»

«Να σας εξηγήσω τις επιλογές και αποφασίζετε εσείς»

«Εσείς γνωρίζετε καλύτερα τις ανάγκες σας»

Φράσεις που δείχνουν συμβουλευτική πώληση

«Με βάση αυτά που μου λέτε...»

«Από τη χρήση που μου περιγράφετε...»

«Για τη δική σας περίπτωση...»

«Αυτό που θα σας πρότεινα...»

«Αυτό που βλέπω ότι σας ταιριάζει...»
