Όταν ο πελάτης είναι δύσκολος

«Δεν θέλω να σας πείσω να πάρετε κάτι που δεν χρειάζεστε. Θέλω απλά να δω αν υπάρχει λόγος να το εξετάσετε.»

Όταν φοβάται αλλαγή

«Το σημαντικό δεν είναι μόνο να αλλάξει κάποιος πάροχο. Είναι να ξέρει γιατί αλλάζει.»

Όταν λέει «όλοι τα ίδια λέτε»

«Το καταλαβαίνω. Γι' αυτό δεν θέλω να σας πω απλά ότι είναι καλύτερο. Θέλω να δούμε αν ταιριάζει στη δική σας χρήση.»

Όταν βιάζεται

«Θα σας κάνω μόνο δύο ερωτήσεις. Αν δεν σας αφορά, σταματάμε εκεί.»

Στόχος: μην συγκρίνει μόνο την έκπτωση. Βοήθησέ τον να κοιτάξει τιμή + τεχνολογία + εμπειρία χρήσης.
«Όταν ένας πελάτης αποφασίζει να αλλάξει πάροχο, είναι πιθανό ο προηγούμενος πάροχος να επικοινωνήσει με καλύτερη προσφορά για να τον κρατήσει.»
«Αν συμβεί αυτό, κοιτάξτε όχι μόνο πόσα ευρώ θα πληρώνετε, αλλά και τι υπηρεσία θα έχετε στο σπίτι σας.»
«Με αυτή την τιμή τι ακριβώς παίρνω; Παραμένει η ίδια τεχνολογία ή αναβαθμίζεται και η σύνδεσή μου;»
«Και αυτό έχει αξία. Η εμπιστοσύνη είναι σημαντική. Απλά αξίζει κάθε λίγα χρόνια να βλέπουμε αν η υπηρεσία συνεχίζει να καλύπτει τις ανάγκες μας.»
«Αυτή η τιμή συνοδεύεται από αναβάθμιση σε Fiber ή απλά είναι μια έκπτωση για να παραμείνω;»
Κράτα αυτό

«Η διαφορά δεν είναι μόνο τι πληρώνετε σήμερα, αλλά τι σύνδεση θα έχετε τα επόμενα χρόνια.»

«Φυσικά. Απλά να έχετε υπόψη σας ότι μπορεί να δεχτείτε μετά μια προσφορά παραμονής. Μην συγκρίνετε μόνο την έκπτωση — συγκρίνετε και αν η υπηρεσία που θα έχετε είναι αυτή που πραγματικά χρειάζεστε.»
«Αν δεχτείτε κάποια αντιπροσφορά, μην αποφασίσετε μόνο από τον ενθουσιασμό της στιγμής. Ρωτήστε τον εαυτό σας: "Αν δεν υπήρχε η έκπτωση, θα επέλεγα ξανά την ίδια υπηρεσία;"»
🔒 Μικρό κλείδωμα πριν φύγεις

«Αν σας καλέσει ο προηγούμενος πάροχος, κρατήστε την ίδια σύγκριση: τιμή + τεχνολογία + εμπειρία χρήσης.»
